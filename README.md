# בוסאן של רועי

אפליקציית ווב (קובץ אחד, בעברית, מותאמת לטלפון) לטיול סולו בבוסאן, 2–6 בנובמבר 2026.

- **היום** — שעון קוריאה, התוכנית של היום הנוכחי וטיפ יומי
- **מסלול** — 5 ימים לפי אזורים, עם סימון של מה שכבר עשית
- **מקומות** — אטרקציות לפי אזור, מועדפים וקישורים ל-Naver Map
- **אוכל** — מנות בוסאניות ומקומות שמתאימים לסועד יחיד
- **לינה** — Plea De Blanc Hotel & Residence, כתובת בקוריאנית במסך מלא לנהג המונית
- **כלים** — ממיר וון/שקל, מעקב הוצאות, משפטים שימושיים, טלפונים לחירום וצ׳קליסט

הסימונים נשמרים ב-localStorage במכשיר.

`app.html` הוא קובץ המקור. `./build.sh` יוצר ממנו את `index.html` (פותחים בדפדפן או מפרסמים ב-GitHub Pages).
